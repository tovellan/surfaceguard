# Support

Use GitHub Discussions for usage questions when Discussions is enabled. Otherwise, open a GitHub issue with the support template.

Support covers released SurfaceGuard versions on the Node.js versions listed in `docs/compatibility.md`. Maintainers do not inspect private production artifacts. Reproductions must be minimal and synthetic.

Bug reports should include:

- SurfaceGuard, Node.js, operating system, and framework versions;
- the command used and exit code;
- a reduced policy;
- a synthetic artifact that reproduces the behavior;
- expected and observed findings.

Security reports must follow `SECURITY.md`.
